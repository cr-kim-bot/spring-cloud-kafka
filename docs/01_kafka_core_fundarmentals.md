# Kafka Cluster

- 여러개의 kafka 노드를 묶는 그룹
- 고가용성 확보: 단일 노드에 문제가 생겨도 어플리케이션에 영향을 미치지 않는다.
- 수평 확장성: 어플리케이션은 kafka 단일 노드와 통신을 하게 되고 부하 분산을 위해 여러개의 kafka 노드를 운영한다.
- kafka 노드들끼리 동신을 한다.

# Kafka Node Role

1. 브로커
   - 데이터의 관리 및 저장을 담당
   - 읽기 및 쓰기 요청을 처리 (Producer/Consumer와 통신)
   - 클러스터 내에 여러 브로커를 배치할 수 있다.
2. 컨트롤러
   - 클러스터를 관리하는 역할을 담당
   - 노드 관리
   - 클러스터 내에서는 하나의 액티브 컨트롤러만 존재
   - 컨트롤러는 클라이언트와 통신하지 않음
   - 컨트롤러가 장애가 나면 다른 노드줄에서 컨트롤러를 선출
   - `process.roles` 속성을 통해 역할 지정 `broker` `controller` `broker,controller`
